OpenFocusd - 网站拦截器、追踪器拦截与专注计时器

拦截浪费时间的网站,提升专注力,主动拦截追踪器并保护你的数据。

免费、开源的网站与广告追踪器拦截器,支持站点分组和每日时间限制。零数据收集,无分析后端,无广告。全天候隐私模式。

**适用人群**

OpenFocusd 适合学生、知识工作者、高效能极简主义者,以及任何想要掌控自己在互联网上所接触信息的人——而不只是被动地消费内容。

**简介**

网站拦截器和生产力工具不应该追踪你访问的网站并将其用于营销研究。这就是为什么 OpenFocusd 是 100% 开源且隐私优先的,与 StayFocusd 和 Forest 等其他类似的 Chrome 扩展不同。

OpenFocusd 是一款网站拦截、专注与生产力工具,它按每日计时器拦截令人分心的网站,让工作所需的网站保持可访问,并允许你休息、自主控制拦截设置。它免费、开源(Apache 2.0),并围绕一个简单的原则构建:你的数据留在你的设备上。OpenFocusd 没有任何形式的分析追踪。就是这样。

**工作原理**

创建你自己的"站点分组",例如新闻、社交媒体和视频,然后为令人分心的网站设置每日时间。每个分组都有自己的每日时间额度。当一个分组当天的时间用完时,其中的所有网站将保持拦截状态,直到第二天 6:00 重置。工作或学习所需的网站保留在"允许的网站"中,因此即使 Sanctuary 模式已激活或分组计时器已用完,它们仍然可以访问。

**功能特性**

⏳ 使用指定的每日计时器拦截站点分组,为每个网站类别设置不同的限制。被拦截的网站在每天早上 6:00 重置。
✅ "允许的网站"让工作必需的网站保持可访问,即使其所属分组已被拦截。
🧘 Sanctuary 模式在你设定的时间内将浏览器锁定为仅可访问"允许的网站",专为需要深度专注的时刻而设计。
☯️ 道家/禅宗风格的拦截页面,时间用完时显示来自《道德经》的哲理名言。
🔞 拦截成人与赌博网站列表——开启内置拦截列表,默认拦截这些类别。可拦截超过 52,000 个高风险网站。"始终拦截"用于你永远不想再打开的网站,无需计时器。
🛡️ 追踪器拦截——拦截追踪器、发送全球隐私控制(Global Privacy Control)信号、优先使用加密连接,采用由 DuckDuckGo 维护的公共规则集。所有功能均为可选,在同一个设置页面中切换。
⏱️ 弹出式活动计时器,一目了然地查看每个分组的剩余时间,并可直接从弹窗管理你的分组。

**与众不同之处**

📵 零数据收集——无账户、无分析、无服务器;卸载时自动删除设置
🆓 100% 免费——所有功能永久免费
📖 开源——Apache 2.0 协议,可在 GitHub 上审计每一行代码
🔐 内置隐私保护——唯一同时拦截追踪器的专注工具

**隐私承诺**

OpenFocusd 没有服务器,也没有用户账户。站点列表、计时器和设置由 Chrome 本地存储,并在你卸载扩展时删除。可选的追踪器保护功能会下载由 DuckDuckGo 托管的公共规则集;这些下载绝不包含你的站点列表、计时器或浏览历史。

为了拦截你选择的网站并向你显示拦截页面,本扩展必须能够读取你打开的页面地址。你浏览的任何内容都不会被发送到任何地方。
